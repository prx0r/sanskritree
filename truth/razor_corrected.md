# Aperture Process Identity Theory — Corrected Razor Thesis

## I. Core Ontology

A conscious subject is one concrete, four-dimensionally extended, causally defined process-worldtube that minimally and nondecomposably carries a constitutive task family of maintenance, determination, retention, valuation, counterfactual generation, action, source attribution, and metacontrol.

Let spacetime (M,g) be given. Let Δ(e₀,e₁) = J⁺(e₀) ∩ J⁻(e₁) be a causal diamond defined by invariant causal precedence, not by simultaneity. The constitutive task family:

```
C_i = { T_maint, T_det, T_mem, T_val, T_gen, T_act, T_source, T_meta }
```

Define qualification:

```
Q(W) = Complete(W, C_i, ε, ρ)
    ∧ Reciprocal(G_W^Δ)
    ∧ Nondecomposable(W, Π_i)
```

where G_W^Δ is the graph of temporally extended causal influence among persistent components, built from invariant causal precedence.

The candidate aperture set:

```
W_i* ∈ Min_⊆ { W ⊆ Δ(e₀,e₁) : Q(W) = 1 }
```

The uniqueness conjecture: |Wᵢ*| = 1. This is an explicit empirical conjecture, not smuggled into MaxClosure.

The identity thesis:

```
Dᵢ[e₀,e₁] ≡_inext Wᵢ*[e₀,e₁]
```

Token identity, not production, correlation, or identity with an abstract functional type. The same concrete event is externally accessible as embodied causal organization and intrinsically present as one private phenomenal field.

The phenomenal field:

```
Dᵢ = ⟨Manᵢ, ρᵢ, ∂ᵢ, Uᵢ, τᵢ, Gᵢ, νᵢ, αᵢ⟩
```

A phenomenal present is not an instantaneous slice but a temporally thick intrinsic phase of this worldtube:

```
Dᵢ(e) = Int(Wᵢ* ∩ J⁻(e))_Δτ
```

APIT does not derive manifestness from nonphenomenal premises. It proposes that the demand for such a derivation mistakes two modes of access to one token for two causally related entities.

## III. Relativity Correction

The instantaneous formulation Oᵢ*(t) = Closure(events at simultaneous t) is dead. Special relativity removes any observer-independent global simultaneity relation. Phenomenal co-presence is not integration across a spatial slice; it is co-presentation of causally retained information within one temporally thick process.

Thus:
- Worldtube Wᵢ* replaces time-slice Oᵢ*
- Causal precedence replaces simultaneity
- Phenomenal simultaneity ≠ physical simultaneity of originating events
- Reciprocal causation uses ↝_Δ (temporally extended influence), not simultaneous interaction

## IV. MaxClosure Replaced by Minimal Qualification

MaxClosure across nine dimensions is dead. It requires comparable scales, normalization, trade-off rules, a total ordering, and a reason one compromise is privileged — none currently justified.

Replacement: qualification with inclusion-minimality.

A qualification condition:

```
Q(O) = ∧_k [f_k(O) ≥ θ_k] ∧ Nondecomposable(O, Π)
```

Then:

```
Wᵢ* ∈ Min_⊆ { W : Q(W) = 1 }
```

No weighted sum. No global ranking. No claim that Wₐ > W_b when incomparable across dimensions.

If several incomparable minimal carriers exist, APIT must either predict several subjects, provide an additional exclusion principle, show that only one candidate is dynamically stable, or admit underdetermination.

## VI. Structural Realism as a Rival

Structural realism asks: if complete causal structure is all physics describes, why posit anything beyond it?

APIT's response: phenomenality is not hidden stuff behind structure. The concrete relational process itself has two modes of presentation:

```
Ext(Wᵢ*) = causal-relational process structure
Int(Wᵢ*) = Dᵢ
```

There is no additional bearer Wᵢ* + qᵢ. There is just Wᵢ* under two epistemically asymmetric modes. This makes APIT compatible with process structuralism: Dᵢ ≡_int Rᵢ where Rᵢ is the concrete enacted relational structure, not an abstract graph.

The disagreement with pure structural realism is clean:
- Structural realism: complete causal structure is all there is
- APIT: complete causal structure is one externally accessible aspect of a process intrinsically present as experience

No current experiment selects between these.

## VII. Computational Constraints

APIT does not search every physical subset. Candidate systems are constrained by known causal and anatomical structure:

```
C_candidate << 2^N
```

Constraints include: persistent biological compartments, experimentally measured recurrent networks, known sensorimotor loops, causal intervention results, multiscale modular decompositions, timer-indexed task participation.

The empirical pipeline: candidate generation → task-completeness tests → partition interventions → minimality tests.

Real biological systems may support only confidence regions:

```
Aᵢ^(1-η) = { W : P(Q(W) = 1 | data) ≥ 1-η }
```

The theory may predict probabilistic or scale-dependent aperture boundaries, creating tension with exact phenomenal privacy but more scientifically honest than pretending exact MaxClosure is computable.
