# Extraction: Torella App.II — What Is Memory?

## Source

Raffaele Torella, "Part II: What Is Memory?" in *Utpaladeva, Philosopher of Recognition*, pp. 539-563 (original publication 2007). 2148 lines extracted.

## Core Argument

Memory is the STARTING POINT for Utpaladeva's demonstration that the individual subject coincides with universal consciousness — because "in a very clear manner (suspaṣṭam), memory can serve as a logical reason for the establishment of the identity of the self with the Lord."

## The Structure of the Argument

### 1. The Three Powers (ĪPK 1.3.7)

Utpaladeva identifies three powers (śakti) in the Lord: Cognition, Memory, and Exclusion. After preliminary remarks, he begins a detailed inquiry into each. Memory is treated FIRST, even though it is second in the stated order, because it provides the clearest proof of the identity of the individual subject with Śiva.

### 2. The Buddhist Counter-Model

The Buddhist account: perception produces a saṃskāra (latent trace), which in turn produces the phenomenon of memory. This accounts for OBJECTIVE content — the fact that memory has a certain content — but it LEAVES OUT the SUBJECTIVE component:

> "Memory, in fact, is indeed the memory of the past object but also of the past perception of it." (Torella §5)

The saṃskāra model cannot convey:
- The original perception itself
- The object insofar as it was cognized by that past perception
- The "having been already perceived" quality of remembered content

### 3. The Śaiva Alternative

Memory presupposes "a living organism at work, a dynamic and unitary consciousness able to freely move between different moments of time." (Torella §6)

The key claim: "The one and same svasaṃvedana (self-awareness) of both cognitions creates that necessary bridge between them which the Buddhist epistemologist fails to account for." (Torella §9)

### 4. The "I" as the Bridge

It is the I that ensures the possibility of unifying cognitions occurring at different times:

> "The vimarśa in the memory can connect itself with the vimarśa in the perception and, through it, with the former light of the object — in this way meeting both requirements: taking place in the present and not being divorced from prakāśa." (Torella §10, summarizing Abhinavagupta's ĪPVV)

**The mechanism:** The part-object (arthāṃśe) belongs to the past, but the part-self (svātmāṃśe) is NOT limited by time. The self is the invariant that connects the past perception to the present memory.

### 5. Utpaladeva's Innovation: The YS Definition Changed

The Yoga-Sūtra (I.11) defines memory as: "anubhūtaviṣayāsampramoṣaḥ smṛtiḥ" — "memory is the non-extinction of the object formerly perceived."

Utpaladeva deliberately changes asampramoṣaḥ to asampramoṣaṇam — a subtle shift from a static noun ("non-extinction") to an active process ("non-extinction-ing", implying an agent performing the act):

> "By using the lyuḍanta word [a]sampramoṣaṇa he means to clarify the fact that memory is a function of the agent subject." (Torella, translation)

### 6. Memory Is a Form of Vikalpa

Both ascertainment (niścaya, adhyavasāya) and memory belong to the category of vikalpa, being the "māyic form of vimarśa."

- **Adhyavasāya (determination following perception):** reflective awareness "this" — the object shines and is determined immediately
- **Smṛti (memory):** reflective awareness "that" — the object is determined as previously perceived

The difference is temporal distance, not kind.

### 7. The Puzzle of Memory's Object

A cognition is self-luminous and cannot be the object of another cognition (both Śaiva and Buddhist agree). So how can memory "re-present" a past cognition?

The solution: only a parāmarśa (reflective awareness) of a PRESENTLY shining object is possible. Memory cannot have as its object something that only shone in the past. Therefore:

- What persists is NOT the object but the I that unifies the two cognitions
- The vimarśa in memory connects with the vimarśa in the original perception THROUGH the I, which is not limited by time
- Part-object (arthāṃśe) is past; part-self (svātmāṃśe) is timeless

### 8. The Svalakṣaṇa (Particular) Is Composed of Ābhāsas

The apparently unitary particular (svalakṣaṇa) is composed of multiple "manifestations" (ābhāsa), each having the nature of a universal (sāmānya). What makes an object a particular is the COMBINATION and MUTUAL DELIMITATION of these universals in space and time.

### 9. Vividness Depends on Depth of Manifestation

The vividness (sphuṭatva) of a memory depends on how many ābhāsas are manifested. A memory can range from:
- **Dim (asphuṭa):** limited to one universal abstracted from the whole (e.g. "jar" without specifics)
- **Vivid (sphuṭa):** full particular with spatio-temporal specificity
- **Direct visualization:** intense concentration can produce what amounts to direct perception, though still recognized as past

### 10. The Yogin and Autonomous Mental Constructs

The yogin can directly perceive past objects through intense application (abhiyoga), but this is distinguished from memory because the temporal differentiation has not totally disappeared. Autonomous mental constructs (svatantravikalpa) — pure imagination — can also produce vivid objects, but without the "having been perceived" quality.

### 11. Memory and Exclusion

Memory is connected to exclusion: the ascertainment (niścaya) that constitutes memory operates by "the exclusion of different objects which might be wrongly superimposed on to it." This shows that memory uses Eᵢ (exclusion) in the same way that perception does — the difference is only temporal.

### 12. The Final Conclusion

> "In every cognitive experience, such as memory and so on, it is the freedom precisely of this consciousness-principle to be at work: it is not simply produced thanks to the power of its specific immediate cause."

Memory is not a mechanical product of traces. It is an act of freedom (svātantrya) by consciousness, which bridges time through its own nature.

## Significance for the Aperture Model

1. **Memory provides the temporal continuity (τᵢ) that perception alone cannot.** The I that bridges past and present is the same I that unifies the phenomenal field across time.

2. **Memory is the clearest proof of subject unity.** The Buddhist counter-model (saṃskāra → memory) can explain content retention but not the "pastness" or "mine-ness" of remembered content. This is the same gap we identified in the frontier.

3. **The part-self (svātmāṃśe) is the invariant.** This maps onto our Γᵢ (temporal integration): something persists across time that is not the content.

4. **Memory uses the same exclusion operation (apoha) as perception.** The difference is temporal, not structural.

5. **Memory is an expression of svātantrya (freedom).** It is not mechanically produced — it is an act of consciousness.

6. **The body is not mentioned as the location of memory.** The body appears in TĀ 16.242 as the LIMIT of anusandhāna (connective synthesis), but this memory text discusses the bridging power of the I without specifying a bodily location. This suggests that anusandhāna and the body are connected but not identical — the body is the condition under which connective synthesis operates, not the synthesis itself.
