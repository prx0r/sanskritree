## nirañjana — the Stainless / the Uncoloured
| Attestation | Context |
|-------------|---------|
| TĀ 3.172 | the Supreme Abode; "stain (añjana) = manifestation; nirañjana = stainless AND unmanifest" |
| ŚS 1.1 (via Vārttika 1-15) | unobscured (anāvṛta) consciousness = Śiva-nature — the same doctrine without the word |
| AK 97 | nirālambapadaṃ śāntaṃ tathātītaṃ nirañjanam — the state beyond the kula's support |
| KJN 3.9 | sarvavyāpī nirañjanaḥ — the pervasive lotus above the cakra-arithmetic |
| KB 1.2/9.15 | nirañjanapada — the station of the Stainless, attained via the formless |

**Best usage:** the terminus of the apophatic ascent in every tradition of the batch; *never* merely "pure" — it carries the unmanifest/uncoloured sense (TĀ gloss). Consistent rendering: Stainless (capitalized) or Uncoloured when the māyā-stain reading is live.

## yoni / yonivarga / yonimudrā — the source / the four powers / the gesture-state
| Attestation | Context |
|-------------|---------|
| ŚS 1.3 | yonivargaḥ kalāśarīram — Bhāskara: yonayaḥ śaktayaś catasraḥ (Ambā, Jyeṣṭhā, Raudrī, Vāmā) |
| ŚS 2.7 bracket | ambā-jyeṣṭhā-vāmā-raudrīrūpaṃ śakticatuṣṭayaṃ — the SAME four as Mātṛkā's manifestation |
| KB 1.5 | vṛhadyoni — the Great Yoni (the vidyā as womb-source; Ciñcinī/Kubjikā triangle) |
| KB 1.12 | yonimudrā — the practice-condition; Ācārasāratantra: "entering the yoni-mudrā, recites the mantra" |
| ŚS 2.7 bracket | yonyātmāśaktollāsa — the "celebration of the yoni-natured power" |

**Best usage:** yoni is *never* sexual by default in this literature — it is the śakti as source (Bhāskara glosses it outright: yonayaḥ śaktayaḥ); the fourfold (Ambā/Jyeṣṭhā/Vāmā/Raudrī) is a fixed technical list spanning Trika and Kula lines; yonimudrā = the entered state of mantra-practice, paired with śravaṇa (hearing) of the root-vidyā.

## mātṛkā — the Matrix (the alphabet as the goddess)
| Attestation | Context |
|-------------|---------|
| ŚS 1.4 | jñānādhiṣṭhānaṃ mātṛkā — the ground of knowledge |
| ŚS 2.7 | mātṛkācakrasaṃbodhaḥ — Mātṛkā = svābhāsā kriyāśaktiḥ parā; her wheel = the kalā-aggregate |
| KB (v2, 1.9–1.32 notes) | the vidyā's body (from the Śrītantrasadbhāva quote in the anchor: "energy is Mātṛkā... Śiva's nature") |
| TĀ (vol. 2, via anchor) | the 50 phonemes as the body of consciousness |

**Best usage:** Mātṛkā (capitalized, transliterated) = the power of action as the alphabet-matrix; never "alphabet" in translation — the goddess-load is essential; her "wheel" (cakra) = the aggregate of the phonemic energies (kalāsamūha).

## icchā / icchāśakti — will, the first power
| Attestation | Context |
|-------------|---------|
| ŚS 1.13 | icchāśaktir umā kumārī — will = Umā the maiden |
| ŚS 2.7 bracket | icchāśakteḥ prāṇanatmatāvatāre — will entering the life-breath |
| KJN 2/6–2/7 | kriyā līyati icchayā; icchāśaktir layaṃ yāti yatra tejaḥ paraḥ śivaḥ — the descent chain jñāna ⊃ kriyā ⊃ icchā ⊃ tejas |
| ŚS 1.6 (via 1.5's Vārttika) | the triad icchā/jñāna/kriyā as the powers of the wheel |

**Best usage:** icchā is the *first* power (the summit of the descent-chain); it is never "wish" — in this literature it is the divine will-power, identified with the goddess (Umā). The chain jñāna → kriyā → icchā → tejas (KJN) is the standard ladder.

## kalā — phonemic energy / obscuring energy
| Attestation | Context |
|-------------|---------|
| ŚS 1.3 | kalāśarīram — the body of the kalās = the phonemes A–Kṣ |
| ŚS 2.7 | kalāsamūha — the aggregate of her powers |
| TĀ (anchor) | kalayati — "that which generates diversity"; the kṣemarāja etymology |
| KB 1.12 note | (the vidyā's kalās) |

**Best usage:** kalā = the unit-energy (especially phonemic); "obscuring energy" only where the binding function is explicit (1.3 in the anchor's rendering); otherwise "energy-unit" — the term straddles phonology and ontology.

## bindu / visarga / liṅga — point / emission / mark
| Attestation | Context |
|-------------|---------|
| KJN 3/10–3/11 | the liṅga = the formless mark in which the world is dissolved |
| KJN 3/20 | niṣkrāntā bindumadhye — issued from the bindu, whirled up |
| AK 15–18 | na bindubhedake — not in the piercing of the bindu (negation!) |
| ŚS 2.7 bracket | binduṃ prollāsya... visargaṃ pradarśitavatī — the pure path in seed-form + the emission |
| KB (vidyā-complex) | (the vidyā's bindu) |

**Best usage:** the Kula-cosmology triple: bindu (the seed-point of the pure path), visarga (the emission into manifestation), liṅga (the mark = the formless terminus). AK's *negation* of the techniques shows the Akulavīra's iconoclasm — the same terms, used negatively.

## paśu / pati — bound soul / Lord
| Attestation | Context |
|-------------|---------|
| ŚS 1.8 Vārttika | paśūnāṃ svarūpahāni... patīnāṃ svarūpasphūrti |
| ŚS 1.15 (bracket) | the paśu vs the awakened |
| ŚS 2.9 (bracket) | paśur iva adharāvasthām — the bound one's clinging |
| KB 1.12 | paśoragre — never before the bound one |
| KJN 3/17 | paśavo jñānavarjitāḥ — the bound are knowledge-less |

**Best usage:** the fixed pair paśu/pati (bound/Lord) — never "animal/Lord" in this philosophical layer (the etymological link paśu-pāśa holds but the bound-soul sense dominates); "the fettered" for paśu when in ritual context.

## sahaja / svābhāvika — innate / natural
| Attestation | Context |
|-------------|---------|
| ŚS 2.5 | svābhāvikaṃ syāt sahajaṃ balam — the innate power |
| AK 1, 5, 14 | sahajānanda — the bliss of the innate |
| ŚS 2.1 (title) | sahajavidyodaya — the arising of innate vidyā (the prakaraṇa's own name) |

**Best usage:** the innate/uncrafted pair marks the non-technique path — the philosophical heart of the Śāktopāya and the Akulavīra's claim alike. "Innate" for sahaja, "natural" for svābhāvika (with the pair noted when they co-occur, as at ŚS 2.5).

## naṭa / naṭavat — the actor
| Attestation | Context |
|-------------|---------|
| ŚS 1.2 Vārttika (bracket) | naṭasyeva — the Lord assumes the role of the bound soul like an actor |
| ŚS 2.9 (bracket) | prabuddhanaṭavat — the awakened one acts like an actor |
| APS vv. 22–24 (our Siddhitrayī) | the Lord as actor (the same image in Utpaladeva) |

**Best usage:** the actor-metaphor is a signature image of this lineage (Bhāskara + Utpaladeva): the Lord *performs* the world without being bound; the awakened one *performs* saṃsāra like an actor. Three attestations across two authors today — flag as a lineage-motif for the scholar-facing notes.

## vidyā / avidyā / vidyā-śravaṇa — the (innate) knowing / ignorance / hearing-as-liberation
| Attestation | Context |
|-------------|---------|
| ŚS 2.3, 2.5, 2.10 | vidyā = the sudden self-opening; aviśiṣṭā vidyā = the common world-perceiving knowledge; vidyāsaṃhāre = its withdrawal |
| KB 1.15–1.20 | the Daśamahāvidyā list; śravaṇamātreṇa jīvanmukti — liberation by hearing alone |
| KJN (frame) | jñāna/kriyā/icchā chain — vidyā as the content of the transmission |
| Ācārasāratantra | yonimudrāṃ vijānāti mūlavidyāṃ śṛṇoti yaḥ — knowing the mudrā, HEARING the root-vidyā |

**Best usage:** vidyā in the Trika = the innate self-knowing (sahajavidyā), in the Kālīkula = the goddess-as-teaching (the Mahāvidyās); the *hearing* (śravaṇa) of the vidyā is the liberating act in both — the cross-tradition convergence is the register's headline finding. "Vidyā" is kept untranslated in both lines (it is a proper-noun-level term).
