# What the Heck Is Memory?

## A scientific deep-dive connecting Torella's memory argument to modern neuroscience, Levin, CIMC, and the aperture model.

---

## Preamble: Why Memory Matters

Memory is where **mechanism, temporality, selfhood, and phenomenal ownership intersect**. Torella's reconstruction identifies a real explanatory pressure, but modern neuroscience changes its form. Contemporary science no longer treats memory as a passive trace that simply reproduces an object. It treats remembering as a distributed, reconstructive act involving hippocampal indexing, cortical reinstatement, temporal-context recovery, source attribution, bodily self-location, value, and present-state inference.

That means the old contrast:

```
Buddhist trace versus unitary Śaiva subject
```

must become:

```
distributed reconstructive machinery versus the first-person
unity of recollection
```

Science now explains much more than the simple saṃskāra model Torella criticizes. But it still does not straightforwardly explain why retrieved information is experienced as:

> **I previously underwent this.**

That remains the real frontier.

---

## Part 1: Memory Is Not One Phenomenon

The word "memory" currently hides at least six distinct problems:

| Problem | Definition |
|---------|------------|
| **Storage** | What physical changes persist after an event? Sₜ₀ → ΔOᵢ → Sₜ₁ |
| **Retrieval** | How does a present cue reactivate information related to an earlier episode? |
| **Reconstruction** | How are distributed features assembled into a presently usable scene? |
| **Pastness** | Why is the reconstructed content represented as belonging to an earlier time? |
| **Mine-ness** | Why is it represented as something I underwent rather than as a fact or fantasy? |
| **Phenomenal reliving** | Why does some retrieval involve an experienced return to a past episode? |

Torella's argument is strongest concerning the final three — not storage alone.

---

## Part 2: What Modern Engram Science Explains

An engram is not best understood as a miniature picture stored in one place. It is a distributed population of cells altered by learning and capable of contributing to later retrieval.

Current research emphasizes both stability and flexibility. Engram representations can reorganize over time, recruit new circuitry, lose detail, and change through retrieval and reconsolidation. Hippocampal-cortical replay may help bind and redistribute memory components, while recent work shows that time-dependent reorganization within hippocampal circuitry itself can explain declining precision in remote memory. (PubMed 40369077)

This strongly supports Torella's rejection of memory as simple conservation:

```
remembering is not passive non-extinction of an object
```

Instead:

```
remembering is a present reconstruction caused and constrained
by a persisting distributed organization
```

The shift from the Yoga Sūtra's static *asampramoṣa* to Utpaladeva's active *asampramoṣaṇa* is therefore unexpectedly compatible with current science.

A modernized formulation:

```
Memoryᵢ(e) = ActivelyReconstructᵢ(e | Γᵢ, qₜ, Cₜ)
```

Where Γᵢ is developmental and learning history, qₜ is the present retrieval cue, and Cₜ is the present bodily, affective, and semantic context.

---

## Part 3: Hippocampal Indexing as a Candidate for Anusandhāna

Hippocampal indexing theory proposes that the hippocampus records an index to the distributed cortical activity associated with an episode. A partial cue can reactivate that index, which in turn reinstates components of the cortical pattern. (PubMed 17696170)

Formally:

```
eₜ = {c₁, c₂, ..., cₙ}
```

is encoded through an index:

```
hₑ = Index(c₁, ..., cₙ)
```

At retrieval:

```
q → hₑ → {ĉ₁, ĉ₂, ..., ĉₙ}
```

This is a powerful physical candidate for connective synthesis. But *anusandhāna* appears to demand more than feature binding. It connects the original cognition, the present cognition, the fact of prior occurrence, and the self that underwent both.

Therefore hippocampal indexing may implement content connection without by itself explaining first-person temporal identity.

The useful decomposition:

| Component | Symbol | Function |
|-----------|--------|----------|
| Episodic feature indexing | Hᵢ | Feature binding across cortex |
| Temporal-context recovery | Tᵢ | When the event occurred |
| Self/source attribution | Sᵢ | Who experienced it |
| Autonoetic reliving | Aᵢ | Re-experiencing the event |

A complete neural counterpart to *anusandhāna* would require all four.

---

## Part 4: Temporal Context — How Science Represents "That Was Before"

Modern temporal-context theories propose that events are encoded together with a slowly changing contextual state. During retrieval, reinstating an event partially reinstates its temporal context, which then cues related events. Such models explain contiguity, recency, sequence structure, and some reconsolidation effects. (PMC 2600676)

Let cₜ be a drifting temporal context. Encoding binds eₜ ↔ cₜ. Retrieval of eₜ reinstates ĉₜ, which distinguishes it from the present context ĉₜ ≠ c_now. This gives a plausible mechanism for **pastness**:

```
Past(e) ≈ content reinstated with a context represented as
          noncurrent but belonging to the present trajectory
```

Recent work on neural representations of episodic time stresses that temporal context is affected by arousal, event boundaries, contextual drift, and the structure of episodes. (PMC 12614068)

This is a major scientific response to Torella. The trace model need not only preserve an object. It can preserve or reconstruct: sequence position, source, context, temporal distance, and relation to the current event.

So the strong claim "A trace can never explain pastness" is no longer secure. A better claim:

```
Context reinstatement can explain how a system classifies
content as past, but not automatically why that classification
is lived as my past.
```

---

## Part 5: Autonoetic Consciousness — The Exact Modern Counterpart

Tulving distinguished episodic memory from semantic knowledge through **autonoetic consciousness**: awareness of oneself as the subject who experienced an event in the past.

Current work defines it approximately as awareness that a remembered or imagined event is one that one oneself experienced or could experience. Researchers still debate how to measure it because subjective reliving cannot be reduced to simple accuracy. (ScienceDirect 2024)

This is almost exactly Torella's target.

| Memory type | Definition |
|-------------|------------|
| Semantic | I know that event e occurred |
| Episodic recollection | I remember myself undergoing e |

The second includes: content + pastness + first-person ownership + reliving.

So the deepest bridge is:

```
svātmāṃśa ↔ autonoetic self-location through subjective time
```

But they should not be identified without qualification. Utpaladeva treats the self-side as an invariant consciousness not limited by time. Cognitive neuroscience typically treats autonoesis as a constructed capacity dependent on hippocampal, cortical, bodily, metacognitive, and self-representational processes.

The exact dispute:

```
Does autonoesis reveal a persisting subject, or does a
constructed self-model generate the appearance of a
persisting subject?
```

---

## Part 6: The Self-Reference Effect — "Mine" Changes Memory

Modern memory science strongly confirms that self-relevance is not an incidental label applied after retrieval. Information encoded in relation to oneself is generally remembered better. Even arbitrary ownership assignments can improve later source memory, and recent lifespan work finds a robust advantage for items represented as self-owned rather than other-owned. (PMC 6652178)

This means Mineᵢ(x) actively changes: encoding strength, organization, attentional priority, value, and later retrieval probability.

Thus Torella is right that the subjective dimension is not captured by a content-only trace. But modern science supplies a naturalistic interpretation:

```
"Mine" may be an encoding and retrieval operation performed
by a self-model, rather than evidence for a timeless
metaphysical self.
```

The relevant mechanism may involve interaction among: medial prefrontal self-processing, hippocampal episodic binding, posterior midline autobiographical networks, affective salience, and bodily self-models.

The self-reference effect therefore supports: self-relation is causally constitutive of memory organization. It does not select between a substantial self and a dynamically maintained self-model.

---

## Part 7: Bodily Self-Consciousness and Episodic Memory

Modern research increasingly shows that bodily self-location influences episodic encoding and recall. Virtual-reality experiments manipulating bodily self-consciousness suggest that first-person bodily perspective contributes to later episodic memory for events. (Nature Scientific Reports 2023)

This is important for TĀ 16.242: "knowledge in one body cannot perform anusandhāna with cognition in another body."

A scientific reconstruction:

```
Episodic integration is indexed not merely to an abstract
identity but to one embodied spatiotemporal trajectory.
```

Define Γᵢᴮ as the continuous embodied trajectory of agent i. Then an event is remembered as mine when it is reconstructed as belonging to Γᵢᴮ:

```
Mineᵢ(e) ≈ BelongsTo(e, Γᵢᴮ)
```

The Śaiva interpretation says the same timeless "I" illuminates both moments. The naturalistic interpretation says the current system reconstructs both moments as stages of one bodily and autobiographical process.

---

## Part 8: Memory Is Constructive, Not Reproductive

Current episodic-memory theory increasingly treats memory as scenario construction. A recent framework proposes that episodic traces retain a gist or scenario structure that can be recombined with present constraints to reconstruct plausible episodes. Episodic memory shares mechanisms with future simulation, counterfactual imagination, planning, and spatial construction. (PMC 11482257)

This strongly converges with Utpaladeva's placement of memory and imagination within *vikalpa*. Both memory and imagination are present acts of construction:

| Operation | Process |
|-----------|---------|
| Imagination Iᵢ | Zᵢ → ê_possible |
| Memory Mᵢ | Zᵢ + Γᵢ + PastTag → ê_past |

The difference is not necessarily vividness or complexity of content. It is the source constraint:

```
Memory: ê is attributed to prior experience
Imagination: ê is not attributed to prior experience
```

This is almost precisely Torella's distinction between vivid autonomous construction, vivid yogic visualization, and memory retaining the "already perceived" quality.

---

## Part 9: Source Monitoring May Answer Part of the Buddhist Objection

Source-monitoring theories explain how cognition attributes a present mental representation to: perception, memory, imagination, testimony, inference, or another person.

This attribution uses features such as: perceptual detail, spatial and temporal context, emotional information, cognitive effort, internal consistency, and causal history.

Thus the "having been perceived" quality may be implemented as:

```
Source(x) = prior self-perception
```

rather than requiring direct survival of the original perception. This substantially strengthens the naturalistic rival.

A system could reconstruct ê and infer Source(ê) = SelfPerceptionₜ₋₁. That would explain why memory is presented as "previously perceived by me."

But the Śaiva can still press: for whom is this source attribution presently manifest, and what unifies the prior and present first-person poles? The debate moves from whether traces can encode pastness to whether mechanistic source attribution explains **experienced first-person identity**.

---

## Part 10: False Memory and Reconsolidation Pressure the Timeless-Invariant Reading

Every act of retrieval can alter the remembered episode. Memories may incorporate later information, current goals, emotional state, and reconstruction errors. Engram research now emphasizes flexibility, while reconsolidation models show how retrieved contextual states can update memory. (Nature 2024)

This creates pressure on a simplistic invariant-self account. If the same timeless "I" guarantees memory unity, it does not guarantee: accuracy, unchanged content, correct ownership, correct source, or correct temporal placement.

A memory can feel mine and past while being partly or wholly false. Therefore:

```
Mineᵢ(e) + Past(e) ⇏ ActuallyExperiencedᵢ(e)
```

Autonoetic form is separable from veridicality. The "I" may provide the form of connection without proving that the connected content is historically accurate. That is compatible with Utpaladeva if his argument concerns the possibility of connection rather than infallibility. But it prevents using subjective certainty as proof of metaphysical persistence.

---

## Part 11: Amnesia Reveals Multiple Layers of Continuity

Neurological dissociations show that several kinds of memory can be lost while organismic identity, perception, skill, affect, or semantic knowledge remain. The hippocampus is especially important for episodic memory, while factual learning and procedural capacities can show partial preservation under some forms of hippocampal damage. (PubMed 9662134)

This produces a hierarchy:

| Level | Type | Definition |
|-------|------|------------|
| 1 | Γᵢ_bio | Biological continuity |
| 2 | Γᵢ_procedural | Skills and habits |
| 3 | Γᵢ_semantic | General knowledge |
| 4 | Γᵢ_episodic | Personally relived events |
| 5 | Γᵢ_narrative | Explicit life story |

These can dissociate. Therefore episodic memory cannot be the sole condition of phenomenal subjecthood. A person with severe episodic amnesia may remain conscious in the present.

So:

```
Memory explains temporal self-extension, not the existence of
momentary manifestness.
```

This places Torella's memory argument at a specific level:

```
memory → diachronic subject unity
```

not:

```
memory → consciousness as such
```

## Part 12: The Levin Connection — Memory Outside Brains

Levin's work makes the concept of memory much broader. In developmental and regenerative biology, tissues can retain target morphologies, anatomical setpoints, or bioelectric patterns and later act to restore them after perturbation. Planarian tissue can retain experimentally induced bioelectric states for extended periods, and computational models treat these as rewritable somatic pattern memories. (PMC 7935058)

This is not episodic autobiographical memory. It is:

```
memory as persistence of a goal, attractor, or target
configuration across material turnover
```

Define mᵢ_morph = stored target morphology. The system compares xₜ against mᵢ_morph and acts to reduce εₜ = d(xₜ, mᵢ_morph). This resembles *smṛti* in the broad sense of keeping a form available across time. It does not include remembered experience, pastness, ownership, or reliving.

### Levin gives us at least four kinds of biological memory

| Type | Definition |
|------|------------|
| Molecular | Persistent biochemical states |
| Cellular | Changes retained by individual cells |
| Collective bioelectric | Stable network-wide patterns across tissues |
| Morphological | The target form toward which a system regulates |

These show that temporal persistence of information is possible without a nervous system and without evidence of autobiographical selfhood. This prevents overidentifying *smṛti* with episodic recollection. Aperture theory needs a hierarchy.

## Part 13: A Hierarchy of Memory for the Aperture Model

| Level | Name | Definition | Example |
|-------|------|------------|---------|
| 0 | Structural persistence | A state remains physically stable | Persistent molecular state |
| 1 | Adaptive trace | Past interaction changes future response | Conditioning, cellular adaptation |
| 2 | Target-state memory | System restores a preferred configuration | Levin morphogenetic memory |
| 3 | Associative reconstruction | Partial cues reactivate distributed content | Hippocampal indexing |
| 4 | Source and temporal attribution | Content identified as previously perceived | Source monitoring |
| 5 | Autonoetic recollection | Event relived as part of my past | Episodic memory |
| 6 | Narrative integration | Events organized into a model of my life | Autobiographical memory |

The mistake made by both simplistic mechanists and metaphysicians is to move directly from Level 1 or 2 to Level 5. Levin establishes Levels 1–2 convincingly. Neuroscience increasingly explains Levels 3–4. The unresolved phenomenological problem lies especially at Level 5.

## Part 14: Memory and Causal Emergence

Memory helps identify the scale at which a biological individual exists. Suppose local components retain only short-range states, while a larger network retains a long-term target or episodic trajectory: M_parts < M_whole. Then the macro-system has memory inaccessible to any single component. This can produce causal emergence: CE_macro > CE_micro.

The macro-level process becomes the relevant bearer of long-term policy, target state, source history, error correction, and identity over turnover. This suggests a powerful aperture criterion:

```
The candidate subject-scale should be the maximal scale at
which memory can guide counterfactual system-level action
across time.
```

Call this **mnemonic causal closure** (MCᵢ). But again: MCᵢ ⇏ phenomenal memory.

## Part 15: Memory and CIMC

CIMC's second-order-perception architecture requires memory for several reasons. A system cannot model its own cognition without retaining prior internal states, predictions, confidence, errors, consequences of policy, and changes caused by self versus environment.

Thus a CIMC agent needs:

```
P⁽²⁾(t) = F[P⁽¹⁾(t), Mᵢ(P⁽¹⁾_{<t}), Mᵢ(P⁽²⁾_{<t})]
```

This produces a candidate for reflexive temporal continuity:

```
I predicted x. I observed y. My prediction was wrong.
I should revise my model.
```

The pronoun "I" can be operationalized as the persistent process whose stored states and future policies are updated.

### A weak machine memory

Retrieval-augmented storage: q → database lookup → x.

### A stronger aperture memory

A retrieved event is tagged as originating in the system's own trajectory, updates current confidence and goals, changes its self-model, constrains future counterfactuals, can be distinguished from externally supplied information, and remains causally owned by the same process.

Thus machine episodic memory requires more than retrieval; it requires source-sensitive incorporation into one persistent self-modifying trajectory. Even this does not prove autonoetic consciousness, but it is the correct functional target.

## Part 16: The Exact Scientific Rival to Utpaladeva

The strongest naturalistic reply is no longer "a trace produces a memory." It is:

1. An episode changes a distributed neural system
2. Hippocampal indexing binds its components
3. Consolidation reorganizes the representation
4. Temporal context encodes its location in a sequence
5. Source-monitoring processes classify it as previously perceived
6. Bodily and autobiographical self-models classify it as mine
7. Cortical reinstatement and imagery produce reliving
8. Metacognition produces confidence that remembering is occurring

Formally:

```
Rememberᵢ(e) = F(Engᵢ, Idxᵢ, Ctxᵢ, Srcᵢ, Selfᵢ, Imgᵢ, Metaᵢ)
```

This is a formidable explanation. It can potentially explain content, vividness, pastness, source, ownership, confidence, reconstruction errors, false memories, and gradations of reliving.

Utpaladeva's remaining challenge:

```
Why are all these present operations given as one first-person
act rather than merely coordinated information processing?
```

That is no longer a special problem of memory. It is the general manifestness and co-presence problem instantiated diachronically.

## Part 17: What "The I Is Not Limited by Time" Can Now Mean

Three possible interpretations:

| Interpretation | Definition |
|---------------|------------|
| Strong metaphysical | One numerically identical consciousness literally exists unchanged through past and present: Iₜ₁ = Iₜ₂ |
| Process | Different temporal stages belong to one continuing causal process: Oᵢ(t₁) ∼Γᵢ Oᵢ(t₂) |
| Model-based | The current system represents past and present stages as belonging to one self: SMᵢ(t₂)[Oᵢ(t₁) ∼ Oᵢ(t₂)] |

These are not equivalent. Science strongly supports process continuity and self-modelling. It does not by itself establish a timeless consciousness.

The inexternalist option:

```
The persisting process is intrinsically lived as one temporally
extended field.
```

This is stronger than model-based continuity but does not require an unchanging substance.

## Part 19: The Most Important Experiments

### Experiment 1 — Pastness without ownership

Create or identify states in which participants know an event happened, locate it in the past, but lack a sense of personally reliving it. This separates Past from Mine + Relive. Semanticized autobiographical memories and some forms of amnesia may be useful.

### Experiment 2 — Ownership without accuracy

Compare true and false autobiographical memories that are both strongly experienced as mine. This tests whether Mineᵢ depends more on self-model integration than historical fidelity.

### Experiment 3 — Bodily perspective manipulation

Manipulate first-person versus observer perspective during encoding and retrieval. Measure contextual accuracy, vividness, self-ownership, emotional intensity, and autonoetic reliving. This directly tests the body-indexed anusandhāna hypothesis.

### Experiment 4 — Memory boundary under split integration

Study conditions where information is retained locally but unavailable to the system-level narrative or report. Prediction: local trace ≠ aperture-level memory.

### Experiment 5 — Artificial trajectory ownership

Build two agents with identical storage. Agent A retrieves records as external facts. Agent B distinguishes self-generated, externally supplied, imagined, perceived, and inferred — and lets retrieval update one persistent self-model and future policy. The difference operationalizes storage ≠ source-sensitive self-memory.

## Part 20: What Memory Now Contributes to the Frontier

Memory does not prove universal consciousness. It gives us three major advances:

### Advance 1 — The aperture is diachronic

A subject cannot be defined solely by simultaneous integration. It must possess a persistent causal trajectory in which past states remain available to alter current determination.

### Advance 2 — Ownership is an operation

"Mine" is not merely attached to a stored content. It changes encoding, retrieval, organization, and action. Thus Ownᵢ belongs inside the aperture architecture.

### Advance 3 — Episodic memory is present construction under historical constraint

Memory and imagination use overlapping generative resources. The critical distinction is source attribution. Memory is imagination constrained by a claimed causal relation to the system's own past. That is extremely close to Utpaladeva's treatment of both as *vikalpa* while preserving the "already perceived" character of memory.

## Final Synthesis

Torella's argument survives, but in refined form. The old Buddhist trace model cannot explain episodic recollection. Modern neuroscience can explain substantially more through: engram + hippocampal index + temporal context + source monitoring + bodily self-model + metacognitive reliving.

This may explain content + pastness + mine-ness + reconstruction. What remains unresolved is:

```
Why do those processes constitute one presently manifest act
of "I remember," rather than a coordinated set of source-tagging
and retrieval functions?
```

The new memory frontier:

```
MnemonicClosureᵢ ⟷? AutonoeticFieldᵢ
```

Where:

```
MnemonicClosureᵢ = Closure(Engᵢ, Idxᵢ, Ctxᵢ, Srcᵢ, Selfᵢ, Γᵢ, Cᵢ)
```

The three interpretations remain:

| Framework | Claim |
|-----------|-------|
| Constructivism | Autonoesis is generated by the memory system |
| Inexternalism | Mnemonic closure IS autonoetic reliving intrinsically |
| Pratyabhijñā | Memory reveals the transtemporal self-manifest consciousness underlying both cognitions |

Levin adds a crucial lower boundary: memory-like persistence and goal restoration begin far below episodic consciousness. Neuroscience fills in the middle: distributed traces can become source-sensitive reconstructions of one embodied history. Utpaladeva presses the upper edge: why is that reconstructed history lived as the past of the same first-person presence?

That is the exact memory problem the next essays should pursue.
