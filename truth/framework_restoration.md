# Framework Restoration Statement

## 1. The Core

```
Dᵢ ≡_int Oᵢ*
```

A conscious subject is one concrete, maximally closed, temporally persistent, embodied process, externally describable as causal organization and intrinsically existing as one private phenomenal field.

## 2. The Aperture

```
Oᵢ* = MaxClosure(Mᵢ, Vᵢ, Iᵢ, Eᵢ, Cᵢ, Sᵢ, Aᵢ, Bᵢ, Γᵢ)
```

## 4. What Got Overfit

The later Buddhist-material analysis accidentally replaced the theory's core with a first-person phenomenology layer. The selfing dynamics, recognition, subtle body — all are downstream proposals about the intrinsic dynamics of an already-identified aperture, not foundations from which the aperture theory is derived.

## 5. The Correct Statement

Aperture Process Identity Theory holds that a conscious subject is a concrete, maximally closed, temporally persistent, embodied process whose memory, endogenous value, counterfactual generation, determination, reciprocal integration, source attribution, agency, and bodily regulation jointly govern one developmental trajectory. That process is externally describable as physical and causal organization and intrinsically exists as one private, unified, temporally extended, valenced phenomenal field. The theory's central empirical and metaphysical wager is that maximal multivariate closure and phenomenal subject unity are two accesses to one concrete token.

The aperture may generate a self-model and a self-preserving appropriative regime within itself. Recognition is a possible recursive transformation in which the aperture ceases to treat that model as an independently grounding owner. If this revision propagates into value, action, embodiment, and future policy, it reorganizes the aperture's subtle-body control interface. First-person contemplative analyses are therefore candidate descriptions of the intrinsic dynamics of an already identified aperture, not foundations from which the aperture theory is derived.

Whether all apertures are local instantiations of a common phenomenal nature or contractions of one universal manifest consciousness remains an explicitly optional metaphysical extension.
