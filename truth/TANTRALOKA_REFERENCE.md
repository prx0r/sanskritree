# Tantrāloka Reference Guide

## The Two Text Sources

### Source 1: GRETIL Sanskrit (gretil_tantraloka.txt)
- **Path:** /root/projects/sanskritree/sources/gretil_tantraloka.txt
- **Lines:** 17,684
- **Content:** Original Sanskrit verses + Jayaratha's commentary with verse markers (AbhT_1.1, etc.)
- **Best for:** Finding verse numbers, checking Sanskrit terms
- **Search tip:** `grep "AbhT_1"` to find chapter 1 verses

### Source 2: Dyczkowski English Translation (11 volumes)
- **Path:** /root/projects/tantraloka/texts/tantraloka-vol*.txt
- **Total lines:** ~337,763
- **Content:** Full English translation with Jayaratha's commentary and Dyczkowski's notes
- **Best for:** Reading actual content, extracting quotes
- **Search tip:** Search by English terms — the translation uses consistent vocabulary

### Source 3: Extra volumes
- **Path:** /root/projects/tantraloka/texts/ (aphorisms-of-siva, doctrine-of-vibration, spandakarika)
- **Other Dyczkowski translations that provide context**

## Search Strategies

### By Concept
- **Manifestation/nature of consciousness:** Search "prakāśa", "light of consciousness", "manifestation"
- **Self-awareness:** Search "vimarśa", "reflective awareness", "self-awareness"
- **Freedom:** Search "svātantrya", "freedom", "autonomy", "independent"
- **Body and contraction:** Search "contraction", "body", "embodied", "limit", "kañcuka"
- **Valence/feeling:** Search "camatkāra", "rasa", "bliss", "ānanda", "aesthetic", "wonder"
- **Epistemology:** Search "prasiddhi", "certainty", "means of knowledge", "pramāṇa"
- **The partition mechanism:** Search "dehabheda", "body difference", "contracts", "separate body"

### By Volume Priority
- **Vol 1** for the COMPLETE PHILOSOPHICAL PROGRAMME — start here for any concept
- **Vol 10** for the PARTITION MECHANISM — dehabhedāt, prāṇa cascade, death, grace
- **Vol 6** for the KANCUKA SYSTEM — technical details of the five coverings
- **Vol 3** for REFLECTION THEORY and RĀGA-NIYATI — the mirror model and craving mechanism
- **Vol 11** for EPISTEMOLOGY — prasiddhi as ground of certainty
- **Vol 4** for THE BREATH AS BRIDGE — prāṇa as first manifestation of consciousness

### Common Pitfalls
- The Dyczkowski translation does NOT embed verse numbers in the text — search by English terms
- Sanskrit terms in the English translation are often in parentheses
- Jayaratha's commentary is mixed with Abhinavagupta's root text — not always clearly separated
- Some volumes (5, 8, 9) have thin philosophical content — they're more about practice and ritual
- The GRETIL text has better verse numbering but is harder to read (Sanskrit + commentary mixed)
- Lines don't correspond 1:1 between the two versions — search by content, not line numbers

## Quick Reference: Most Important Passages

### The Five Most Important Passages for the Frontier

1. **Dehabhedāt (Vol 10: 12113-12125)** — Consciousness contracts due to body differences
2. **Prakāśa argument (Vol 1: 14438-14460)** — Manifestation has transcendental priority
3. **Prāṇa cascade (Vol 10: 7655-7705)** — The bridge from consciousness to body
4. **Rāga-Niyati mechanism (Vol 3: 2199-2220)** — The micro-mechanism of contraction
5. **Prasiddhi epistemology (Vol 11: 13340-13368)** — Certainty is intrinsic, not derived

### The Five Most Beautiful Passages

1. **Camatkāra = my-ness (Vol 1: 1262-1270)** — The experience of blue appearing is wonder
2. **Mirror of consciousness (Vol 3: 19634-19642)** — Manifestation like a reflection, not separate
3. **Ahaṅcamatkāra (Vol 10: ~23760)** — The sense of "I am" IS aesthetic rapture
4. **Body obscures like a chest (Vol 10: 9787)** — The body as that which hides, not contains
5. **Wave upon wave of pulsation (Vol 4: 4101-4106)** — Individual waves in the ocean of the Heart

## Command Cheat Sheet

```bash
# Search a specific volume for a term
grep -n -i "term" /root/projects/tantraloka/texts/tantraloka-vol1-dyczkowski.txt

# Search all volumes
grep -r -i "term" /root/projects/tantraloka/texts/

# Read context around a match
sed -n 'START,ENDp' /root/projects/tantraloka/texts/tantraloka-volN-dyczkowski.txt

# Count occurrences per volume
for vol in /root/projects/tantraloka/texts/tantraloka-vol*.txt; do
  echo "$(basename $vol): $(grep -c "term" $vol)"
done

# Find volume by concept (best first hit)
for vol in /root/projects/tantraloka/texts/tantraloka-vol*.txt; do
  match=$(grep -n -i "key phrase" "$vol" | head -1)
  [ -n "$match" ] && echo "$(basename $vol): $match"
done
```
