# dossiers/ — the 24-lemma corpus

*The reference map's "corpus-learning phase": for each of the 24 high-value lemmas, collect the most informative passages in the Trika/Krama/Kubjikā material — not every occurrence. Each dossier: the lemma's senses by tradition (from the reference map's glossary), the key passages (with our concordance-verified loci), and the working translation-policy.*

## The method (per the reference map)

1. Run the concordance on the lemma.
2. Pick the most informative passages — the ones that show the sense in context — not all occurrences.
3. Tag each passage by tradition (Trika / Krama / Kubjikā / Kaula / Spanda / Pratyabhijñā).
4. Record the translation-policy (the reference map's "krama: sequence, not the school" style rules).
5. Each completed dossier feeds the site's `concepts.ts` + its edges.

*The counts above measure corpus-representation (the Dyczkowski-selection), NOT historical influence — the reference map's selection-effect caveat.*
